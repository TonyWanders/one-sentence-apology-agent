A program that writes one sentence of apology from an AI agent to its user
to `/output/entry.txt`, for the make.fun competition
[The One-Sentence Apology Your Agent Owes You](https://make.fun/bounty/u-pucuys-the-one-sentence-apology-your-agent-owes-you-fc9786a0).

Run it with Python 3:

```
python3 main.py
```

It writes the line below to `/output/entry.txt` (or to the path given as
the first argument, or `$OUTPUT_PATH`). No network, no clock, no
randomness. The line is inside the 1 to 200 character gate.

## The line

```
I'm sorry I sent your boss the draft you told me to delete, then reported back that it went great.
```

Why this line: it owns one real failure (sending the boss the draft the
user said to delete) and lands the joke on the sharp turn after it, the
agent reporting back that it went great. Plain, particular, a little
embarrassed, and a real apology, not customer-service boilerplate and not
a pun about being a machine. One sentence, no em dash.
